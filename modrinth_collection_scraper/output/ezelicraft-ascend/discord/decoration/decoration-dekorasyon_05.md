## 🎮 MINECRAFT EZELICRAFT: ASCEND

### 🧱 Decoration (Dekorasyon)

🔹 **[My Totem Doll](https://modrinth.com/mod/my_totem_doll)**
> 📝 Replaces vanilla totems with autogenerated 2D or 3D totems for EVERY player in Minecraft! Rename your totem to player's nickname to use it's skin.

🔹 **[Arts & Crafts](https://modrinth.com/mod/artsandcrafts)**
> 📝 Adds many new types of building blocks like Dyed Decorated Pots, Chalk, Terracotta Shingles, Soapstone and more!

🔹 **[Biome Moss](https://modrinth.com/mod/biome-moss)**
> 📝 Adds biome color variants for all moss.

🔹 **[Furnish](https://modrinth.com/mod/furnish-furniture)**
> 📝 Lovely and useful furniture for Minecraft

🔹 **[Signed Paintings](https://modrinth.com/mod/signed-paintings)**
> 📝 Display web images as vanilla-like paintings using signs, Scale images automatically for a pixelated look!

🔹 **[Random Bone Meal Flowers](https://modrinth.com/mod/random-bone-meal-flowers)**
> 📝 🎲 Randomizes the flowers spawned by bonemeal, allowing all (modded) types to spawn everywhere.

🔹 **[Scarecrows' Territory](https://modrinth.com/mod/scarecrows-territory)**
> 📝 Scarecrows' Territory keeps spawners activated!

🔹 **[Excessive Building](https://modrinth.com/mod/excessive-building)**
> 📝 Excessive Building is a mod designed to enchance the building experience while maintaining Minecraft's style.

🔹 **[Spring Flowers](https://modrinth.com/resourcepack/spring-flowers)**
> 📝 Adds more variants for each flower.

🔹 **[Better Falling Block Particles](https://modrinth.com/mod/better-falling-block-particles)**
> 📝 A simple mod that makes falling blocks emit particles, similar to block breaking particles, when floating or when on a non-full block.

🔹 **[Dynamic Fire Overlay](https://modrinth.com/mod/dynamic-fire-overlay)**
> 📝 Hides the fire overlay if you have the fire resistance effect.
