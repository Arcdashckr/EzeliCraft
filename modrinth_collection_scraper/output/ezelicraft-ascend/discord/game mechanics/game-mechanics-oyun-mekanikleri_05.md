## 🎮 MINECRAFT EZELICRAFT: ASCEND

### ⚙️ Game Mechanics (Oyun Mekanikleri)

🔹 **[Restart Detector](https://modrinth.com/mod/restart-detector)**
> 📝 Stop sensitive farms and flying machines from breaking on server restarts.

🔹 **[CarpetGUI](https://modrinth.com/mod/carpetgui)**
> 📝 An easy to use GUI for CarpetMod

🔹 **[Creative Dimension](https://modrinth.com/mod/creative-dimension)**
> 📝 A superflat creative dimension for survival worlds.

🔹 **[Oxidize Copper](https://modrinth.com/mod/oxidize-copper)**
> 📝 Quickly oxidize copper blocks using splash thick potions. A great utility to facilitate your building.

🔹 **[NuStone Crafting](https://modrinth.com/mod/nustone-crafting)**
> 📝 A simple data pack which adds the newer stone variants (granite, andesite, diorite, tuff, calcite, and basalt) to the stone tool materials and stone crafting materials tags.

🔹 **[Debug Stick Craft](https://modrinth.com/mod/dsc)**
> 📝 Simple datapack to create a debug stick!

🔹 **[More Dye Recipes](https://modrinth.com/mod/more-dye-recipes)**
> 📝 Allows you to craft dyes from more base components.

🔹 **[Craftable soul soil](https://modrinth.com/mod/craftable-soul-soil)**
> 📝 Allows for the crafting of soul soil in two different ways.
