## 🎮 MINECRAFT EZELICRAFT: ASCEND

### ⚙️ Game Mechanics (Oyun Mekanikleri)

🔹 **[Geckolib](https://modrinth.com/mod/geckolib)**
> 📝 A 3D animation library for entities, blocks, items, armor, and more!

🔹 **[Fzzy Config](https://modrinth.com/mod/fzzy-config)**
> 📝 Config API with automatic GUIs, powerful validation options, server-client sync, and more!

🔹 **[NetherPortalFix](https://modrinth.com/mod/netherportalfix)**
> 📝 Ensures correct destinations when travelling back and forth through Nether Portals in Multiplayer.

🔹 **[Better Third Person](https://modrinth.com/mod/better-third-person)**
> 📝 Improves third person camera view.

🔹 **[Boat Item View](https://modrinth.com/mod/boat-item-view)**
> 📝 See your held items when in a moving boat!

🔹 **[AzureLib](https://modrinth.com/mod/azurelib)**
> 📝 Java Minecraft mod using Bedrock models to create custom models and animations for items, blocks, entities

🔹 **[Double Doors](https://modrinth.com/mod/double-doors)**
> 📝 🚪 Multiple identical double doors, trapdoors and fence gates can be opened simultaneously.

🔹 **[Tree Harvester](https://modrinth.com/mod/tree-harvester)**
> 📝 🌲 Harvest full trees and huge mushrooms instantly with an axe. Includes fast leaf decay and sapling placement.

🔹 **[Bridging Mod](https://modrinth.com/mod/bridging-mod)**
> 📝 Reacharound Placement / Bedrock Bridging for Fabric, Forge & Quilt with a few extra tweaks

🔹 **[SwingThrough](https://modrinth.com/mod/swingthrough)**
> 📝 Allows targeting (and interacting with and attacking) living entities through transparent blocks like grass, crops, and flowers.

🔹 **[Dismount Entity](https://modrinth.com/mod/dismount-entity)**
> 📝 🚏 Allows players to dismount/remove/exit entities/mobs from mounted entities without breaking them.
