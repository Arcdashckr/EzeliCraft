## 🎮 MINECRAFT EZELICRAFT: ASCEND

### ⚙️ Game Mechanics (Oyun Mekanikleri)

🔹 **[Better Conduit Placement](https://modrinth.com/mod/better-conduit-placement)**
> 📝 ✔️ Place conduits in front, makes placing conduit prismarine blocks easier and other tweaks.

🔹 **[Name Tag Tweaks](https://modrinth.com/mod/name-tag-tweaks)**
> 📝 📛 Adds nametag crafting recipe, command, and named entities drop their tag on death.

🔹 **[Surveystones](https://modrinth.com/mod/surveystones)**
> 📝 Adds waystones to surveyor maps like Antique Atlas 4 and Hoofprint.
Supports Blaystones and Fwaystones.

🔹 **[Bigger Sponge Absorption Radius](https://modrinth.com/mod/bigger-sponge-absorption-radius)**
> 📝 🧽 Each extra sponge block placed next to one another increases the water absorption radius.

🔹 **[Better Beacon Placement](https://modrinth.com/mod/better-beacon-placement)**
> 📝 ✔️ Easily place beacon bases by right-clicking the beacons with mineral blocks.

🔹 **[Copper Rails](https://modrinth.com/mod/copperrails)**
> 📝 Enhances minecart transportation with new rails : oxidizable copper rails and crossings

🔹 **[Wiretap](https://modrinth.com/mod/wiretap)**
> 📝 A server-side Simple Voice Chat addon mod for Fabric, that adds a microphone and a speaker block.

🔹 **[Easy Item List](https://modrinth.com/mod/easy-item-list)**
> 📝 Automatically adds server side custom items from recipes to the clients JEI, REI, and EMI!

🔹 **[Simple Voice Chat Radio](https://modrinth.com/mod/simple-voice-chat-radio)**
> 📝 A server-side Simple Voice Chat addon mod for Fabric adding a radio block capable of streaming mp3 radio streams.

🔹 **[Forkcart](https://modrinth.com/mod/forkcart)**
> 📝 Extra features for interesting minecart tracks
