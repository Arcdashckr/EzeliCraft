## 🎮 MINECRAFT EZELICRAFT: ASCEND

### 🛠️ Utility (Yardımcı Araçlar)

🔹 **[MoreLeads](https://modrinth.com/mod/moreleads)**
> 📝 A mod allows you to lead on more entities.

🔹 **[BACAP Language Pack](https://modrinth.com/resourcepack/bacap-language-pack)**
> 📝 Translates BlazeandCave's Advancements Pack into other languages.

🔹 **[Styled Nicknames](https://modrinth.com/mod/styled-nicknames)**
> 📝 Simple, but configurable nicknaming mod allowing your server's players (and admins) to change their nickname with full formatting support

🔹 **[Debug Keys (F3+T) Everywhere](https://modrinth.com/mod/f3-t-everywhere)**
> 📝 Allows you to reload resource packs with F3 + T while not in a world or with a GUI open, useful for speeding up pack development. Now works for all F3 keybinds!

🔹 **[Styled Player List](https://modrinth.com/mod/styledplayerlist)**
> 📝 This mod allows server owners to change player list look!

🔹 **[Fortunate Ancient Debris](https://modrinth.com/mod/fortunate-ancient-debris)**
> 📝 Fortune works on ancient debris! Use fortune-enchanted pickaxes on ancient debris for more netherite scraps

🔹 **[In-Game Brewing Guide](https://modrinth.com/resourcepack/in-game-brewing-guide)**
> 📝 Provides an in-game brewing guide within the "Brewing Stand" UI.

🔹 **[Compact Help Command](https://modrinth.com/mod/compact-help-command)**
> 📝 🗜 Modifies the /help command to show all information, be colourful and have multiple pages.

🔹 **[Shrimp's Distinct Potions](https://modrinth.com/resourcepack/shrimps-distinct-potions)**
> 📝 enhances all bottled beverages and gives each a unique texture!

🔹 **[Fabric Voice Chat Broadcast](https://modrinth.com/mod/fabric-voice-chat-broadcast)**
> 📝 An addon mod to henkelmax's Simple Voice Chat fabric mod
